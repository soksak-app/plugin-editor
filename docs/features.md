- [o] E1 — P1: Open, edit and save a text file of the project, for the core checklist items F102.3, F102.4, F102.5 and F102.10. `surface.opens` declares `*` and `surface.params` `{path}`; the page reads the file through the files sidecar, keeps its line break (`lf`, `crlf`, `cr`, or none) and byte order mark, opens a file with mixed line breaks read-only, reports `tab.modified`, writes in place with the version it read through `editor.save`, follows changes on disk through `watch`, replaces an unmodified text on a change and shows a banner with 다시 읽기 and 덮어쓰기 for a modified one, and shows a failed save as `tab.error`. Done on 2026-10-08: `test/editor.test.mjs` opens, edits, saves, refuses a save over a changed file, overwrites it, keeps CRLF and ignores its own write; `pnpm test` passes 11 tests on macOS 26.6.2 arm64.
- [o] E2 — P1: Find and replace in the open file through a find bar of declared commands: `editor.find`, `editor.find.open`, `editor.find.close`, `editor.find.next`, `editor.find.previous`, `editor.replace` and `editor.replace.all`, with case-sensitive and regular-expression matching, `$&` and `$1` in a replacement, and an invalid regular expression shown as the state of the bar. Command-F opens the bar, Command-Option-F opens it with the replacement field, and Command-S saves. Done on 2026-10-08: the find and shortcut tests pass, and the binder audit of the page with the open bar is empty.
